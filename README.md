# Linear Tools for Houdini

Public downloads and release notes for Linear Tools.

## Downloads

Download the `linear_tools_<version>.zip` attachment from [Releases](https://github.com/daniilstroyev/linear_tools_houdini_releases/releases). GitHub's automatic **Source code** archives are not the installable package.

## Installation

1. Close Houdini.
2. Extract the release ZIP.
3. Copy `linear_tools.json` and the `linear_tools/` folder together into your Houdini user preferences `packages/` directory.
4. Review machine-specific paths in `linear_tools.json` and adjust them for your installation.
5. Start Houdini, open the **Linear** menu, and add the **Linear** shelf.

Current packages target Windows, Houdini 22.0, and Python 3.13. Tools using Redshift or SideFX Labs require those products; Flipbook video encoding requires FFmpeg.

This repository hosts release files and documentation. Development is maintained separately.
